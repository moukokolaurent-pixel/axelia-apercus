# Aperçus de maquettes — Axelia Design

Maquettes de travail destinées à une relecture, **non officielles et non publiées** : elles ne remplacent pas les sites des
entreprises concernées. Chaque page porte un bandeau « maquette », les liens d'appel et d'e-mail sont désactivés, aucun
formulaire n'envoie quoi que ce soit, et les moteurs de recherche sont tenus à l'écart (`robots.txt`, balises `noindex`).

- `atelier-photo/` : proposition de refonte pour L'Atelier Photo Montpellier, accueil actuel
- `atelier-photo-studio/` : la même, avec l'accueil « studio »

Les textes et photos appartiennent à leurs auteurs et ne servent qu'à cette proposition.
